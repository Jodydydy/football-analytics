# Gender/Age — обучение собственной модели (FairFace + UTKFace)

**Дата:** 2026-06-15
**Цель:** дообучить (обучить с нуля поверх ImageNet) свою multi-task модель пол+возраст,
т.к. genderage-голову InsightFace `buffalo_l` напрямую дообучить нельзя (ONNX без train-кода).

## Данные

| Датасет | Фото | Метки | Лицензия |
|---|---|---|---|
| FairFace | 97 698 (train 86 744 / val 10 954) | пол + 9 возр. корзин + раса | **CC-BY 4.0 (commercial OK)** |
| UTKFace | 23 705 | пол + точный возраст 0-116 → маплен в 9 корзин | non-commercial research |

Единый манифест: **121 403 фото** (train 108 078 / val 13 325). Оба датасета уже
выровненные кропы лиц → SCRFD на этапе обучения не нужен.
Возрастные корзины (как у FairFace): `0-2, 3-9, 10-19, 20-29, 30-39, 40-49, 50-59, 60-69, 70+`.

## Модель

- Бэкбон: **MobileNetV3-Large** (ImageNet pretrained), под edge/Jetson.
- 2 головы: пол (binary) + возраст (9 корзин), общий 512-d shared слой.
- Loss: CE(пол) + CE(возраст) с весами классов по обратной частоте (баланс корзин), label smoothing 0.05.
- AdamW lr 3e-4, OneCycle, AMP, 8 эпох, batch 128. ~35 мин на RTX 4060 (8 GB).

## Результаты (val, n=13 325, лучшая эпоха 6)

| subset | n | пол | возраст точно | возраст ±1 корзина | возраст MAE (корзин) |
|---|---|---|---|---|---|
| **all** | 13 325 | **0.930** | **0.555** | **0.944** | **0.512** |
| FairFace | 10 954 | 0.927 | 0.542 | 0.943 | 0.526 |
| UTKFace | 2 371 | 0.944 | 0.616 | 0.947 | 0.447 |

Динамика по эпохам: пол 0.864 → 0.931, возраст ±1 0.794 → 0.944.

### Confusion-матрица возраста (recall по корзинам)
0-2 = 0.89, 3-9 = 0.75, 10-19 = 0.58, 20-29 = 0.59, 30-39 = 0.44,
40-49 = 0.48, 50-59 = 0.44, 60-69 = 0.50, 70+ = 0.61.

Ошибки почти всегда в **соседнюю** корзину (поэтому ±1 = 0.94). Сложнее всего
средние взрослые (30-39, 50-59) — классическая трудность age estimation.

## Выводы

1. **Пол: 0.93** на смешанной in-the-wild выборке (FairFace + UTKFace). Согласуется
   с прошлым выводом, что пол — решаемая задача; здесь это своя обучаемая модель
   (а не pretrained buffalo_l), пригодная для дообучения/дотюнинга.
2. **Возраст: точная корзина 0.56, ±1 корзина 0.94, MAE 0.51 корзины** — на уровне
   ориентиров из литературы для 9-корзинной задачи. ВАЖНО (проверено пересчётом,
   `eval_coarse.py`): крупные корзины **НЕ** дают автоматически >0.9 — упор в
   границу 20-29↔30-39. Реальные цифры по бизнес-сегментациям (val 13 325):
   - **3 группы 0-19 / 20-49 / 50+ → 0.851** (рекомендуемая бизнес-сегментация);
   - 2 группы ≤29 / 30+ → 0.840;
   - 4 группы 0-19/20-39/40-59/60+ → 0.783; 0-9/10-29/30-49/50+ → 0.742.
   То есть для пилота надёжно отдавать **3 крупные группы (~0.85)**, не 4.
3. **Лицензия**: модель обучена в т.ч. на FairFace (CC-BY 4.0), что снимает главный
   юр-блок для коммерческого пилота Альфы (в отличие от ChokePoint/UTKFace).

## Baseline: pretrained buffalo_l vs наша модель (тот же val)

Прогнали готовый InsightFace `buffalo_l` (genderage) на той же val-выборке
(`baseline_buffalo.py`, det_size 256, reflect-pad 0.3, CPU ~52 img/s). Detection
rate 97.4% (12 974/13 325) — метрики buffalo считаны на найденном подмножестве,
т.е. с форой в его пользу (его 2.6% «лицо не найдено» исключены из знаменателя).

| Метрика | buffalo_l (pretrained) | **Наша модель** | Δ |
|---|---|---|---|
| Пол | 0.811 | **0.930** | +12 пп |
| Возраст, 9 корзин (точно) | 0.262 | **0.555** | +29 пп |
| Возраст, 3 группы 0-19/20-49/50+ | 0.652 | **0.851** | +20 пп |

Per-source пол: FairFace 0.796→**0.927**, UTKFace 0.882→**0.944**.

**Вывод: обучение оправдалось.** Даже с форой наша модель обходит готовый
buffalo_l по всем метрикам. Оговорка: в мае на чистом фронтальном ChokePoint
buffalo_l давал по полу 100% — то есть в идеальном фронтальном домене входной
камеры pretrained тоже хорош по полу; наше преимущество максимально на
разнообразных/неидеальных лицах и устойчиво по возрасту в любом случае.

## ONNX-экспорт + инференс-пайплайн

- `export_onnx.py` → `runs/mnv3_v1/mnv3_genage.onnx` (13.9 MB, opset 17, dynamic
  batch). Parity torch vs onnxruntime: max|Δ| ~1e-6, argmax 8/8. Вход
  `input` [N,3,224,224] ImageNet-норм RGB; выходы `gender_logits`[N,2]
  (0=M,1=F), `age_logits`[N,9].
- `infer_genage.py` — 3 слоя для **фронтальной камеры на входе**:
  1. `GenAgePredictor` — кроп лица → {sex, age_bucket, age_group(3гр), probs};
  2. `FaceGenAge` — полный кадр → SCRFD-детект → предикт каждого лица;
  3. `run_video` — IOU-трекер + weighted majority vote (вес = площадь×det_score)
     → `tracks_genage.csv` (пол+возраст на трек). Демо на ChokePoint отработало
     (34 трека; простой трекер без re-ID дробит сильнее майского).

## Кросс-доменный тест (замена Adience, без Kaggle)

`_genage_track_aggregate_ours.local.py` воспроизводит ТОЧНО майский ChokePoint-
трекинг (buffalo детект+embedding re-ID, те же params → те же 28 track_id) и
параллельно гоняет нашу ONNX-модель, затем джойнит с майским user-verified
`true_gender_FILL`. Результат на P1E_S1_C1 (n=28 verified):

| Модель | Пол (gender) |
|---|---|
| buffalo_l (pretrained) | 28/28 = 1.000 |
| **Наша модель** | **27/28 = 0.964** |

Единственный промах — T7 (true F → pred M, лицо в корзине 10-19). Вывод:
наша FairFace/UTKFace-модель **переносится на surveillance-фронтальный домен
(96.4% пол)**, но на «лёгком» чистом фронте buffalo чуть впереди — согласуется
с baseline-выводом (buffalo силён на чистом фронте, наша — на разнообразных).

## Дополнение 2026-06-16 — ретрейн v2b и ФИКСАЦИЯ production-модели

**Цель ретрейна:** поднять возраст 3-группы (0-19/20-49/50+) с 0.851 до ≥0.9 без смены
edge-бэкбона. Бандл `train_v2.py`: DLDL soft гауссовы метки возраста (σ=1.0) + KL-loss,
доп. 3-групповая голова (age3_head), class-balanced sampler ∝(1/freq)^p, 256px, 18 эпох,
EMA(0.999) + OneCycle. Прогон **v2b**: `--sampler-p 0.7` (доля 50+ в батчах 0.133→0.262).

**Результат (val n=13 325, полные 18 эпох, best=эпоха 6):**

| Модель | sampler-p | эпохи | age3 (3-головы) | 50+ recall | пол |
|---|---|---|---|---|---|
| v1 | — | 6 | 0.851 | 0.76 | 0.930 |
| v2 (прерван) | 0.5 | 4/18 | 0.872 | 0.758 | 0.934 |
| **v2b (полный)** | 0.7 | 18/18 | **0.8687** | 0.764 | **0.936** |

**Вывод — потолок ДАННЫХ ≈0.87, цель 0.9 не достигнута.** Усиление семплера 50+ (p=0.5→0.7)
прироста не дало: обе версии садятся на ~0.87 (разница 0.872 vs 0.869 в пределах статпогрешности,
SE≈0.3пп). Причина: 50+ недопредставлен (14k vs 68k у 20-49) — оверсэмплинг гоняет те же лица без
новой информации; при отжиге LR модель кренится к мажоритарной группе (50+ recall к концу 0.764→0.725).
Единственный рычаг к 0.9 — **больше 50+ данных** (AgeDB / IMDB-WIKI elderly / своя разметка), не σ/sampler.

**Решение (user, 2026-06-16): принять 0.87 как реалистичный потолок edge-модели на текущих данных.**
v2b зафиксирована как **production-модель** (всё равно +2пп к v1, пол 0.936, +20пп к buffalo_l на age-3).

**Production-артефакты:**
```
runs/mnv3_v2b/best.pt               — финальный чекпойнт (age3=0.8687)
runs/mnv3_v2b/history.json          — 18 эпох
runs/mnv3_v2b/mnv3_genage_v2.onnx   — ONNX 13.9 MB, opset 17, 3 выхода (gender/age9/age3)
export_onnx_v2.py                   — экспорт 3-головой GenAgeNet2 (parity torch↔ort ~1e-6, argmax 8/8)
infer_genage.py                     — ОБНОВЛЁН: дефолт v2b (256px), age_group из age3-головы;
                                      backward-compat с v1 через --size 224 + --onnx runs/mnv3_v1/...
```
Для фронт-камеры на входе. age_group берётся из выделенной 3-головы (надёжнее коллапса 9-головы).
